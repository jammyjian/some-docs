# 第 14 章 实操考核

本章面向低压电工实操考核,以"知识讲解"的方式介绍实操考核的科目与评分标准、各类实操的要点(仪表使用、电动机控制线路、配电线路与电能表接线、安全操作与触电急救)。

**本章考点**:实操考核的扣分项(如不验电直接作业、接线错误、急救动作不规范)、各类科目的规范动作与评分点。

> 💡 理论机考的考试介绍、答题技巧、易错点和成套练习题,见第 15 章「理论考试应试技巧」。

## 学习提示

- 实操考核重在"规范动作",读这一章时要在脑中"过一遍"整个操作流程。
- 每个科目先记住评分点,再记动作顺序;口述题要说得完整、有条理。
