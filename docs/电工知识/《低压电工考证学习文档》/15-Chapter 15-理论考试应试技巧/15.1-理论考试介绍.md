# 15.1 理论考试介绍

## 本节导读

理论考试是拿证的"第一关",形式是**计算机闭卷考试**,当场出分。这一节把考试的性质、题型、分值、范围、报名流程和考场规则讲清楚,让你上机之前心里有数。

## 一、考试性质

低压电工特种作业操作证考试分为**理论知识考试**和**实际操作考试**两部分,两部分都合格才能发证。

- 理论考试采用**计算机考试(机考)**方式,由各地应急管理部门或其委托的考试机构组织;
- 考试成绩当场显示,不合格的按规定参加补考(次数和间隔以当地通知为准);
- 理论考试通过后,才有资格参加实操考试(部分地区安排顺序相反,以当地考务为准)。

> ⚠️ 各地在题量、时长、及格线、补考规则上会有差异,**一律以准考证和当地考务通知为准**。本节的数值是多数地区的通行情况。

## 二、考试形式与题型

| 项目 | 常见情况 |
|---|---|
| 考试方式 | 计算机闭卷机考,当场出分 |
| 主要题型 | 判断题 + 单选题 |
| 部分地区题型 | 少量多选题 |
| 题量 | 一般 100 题左右(判断题 40~50 题,单选题 50~60 题) |
| 考试时间 | 一般 60~90 分钟 |
| 满分 | 100 分 |
| 及格线 | **80 分** |
| 补考 | 不合格可按规定补考,以当地通知为准 |

### 1. 判断题

- 二选一,只判断"对"或"错";
- 单题分值低,但数量多,是**拿分的基本盘**;
- 常考三类:**绝对化表述、数值、操作顺序**。

### 2. 单选题

- 四个选项中选出**最符合题意**的一个;
- 常见形式:数值题、概念辨析题、场景应用题("应该怎么做");
- 题干里常出现"首先""最主要""应选用""不属于"等关键词,读题时先圈出来。

### 3. 多选题(部分地区)

- 少选、多选、错选通常都不得分(以当地规则为准);
- 策略是"先确定一定对的,再排除一定错的",宁少勿滥。

## 三、考试内容范围

理论考试覆盖低压电工上岗必须掌握的全部知识,大致可以分为七大模块:

| 模块 | 主要内容 | 大致占比 |
|---|---|---|
| 安全生产法律法规 | 安全生产法、特种作业管理制度、电工职责与法律责任 | 约 15% |
| 电工基础知识 | 电路组成、欧姆定律、串并联、交流电、电磁感应 | 约 20% |
| 电气安全技术 | 触电方式、安全电压与安全电流、接地接零、漏电保护 | 约 20% |
| 仪表与低压电器 | 万用表、钳形表、兆欧表、断路器、接触器、继电器 | 约 15% |
| 线路、变压器与电动机 | 导线选择、变压器、三相异步电动机 | 约 15% |
| 配电、照明与防雷接地 | 低压配电系统、照明、防雷与接地 | 约 10% |
| 防火防爆与触电急救 | 电气火灾、灭火器选择、心肺复苏、现场急救 | 约 5% |

> 💡 占比只是估算,不同地区、不同批次的题库权重会有浮动。安全技术、基础知识和法规三块加起来接近一半,是复习重点。

## 四、报名与考试流程

1. **报名**:通过有资质的培训机构或当地应急管理部门指定的渠道报名;
2. **资格审核**:提交身份证明、学历证明、健康承诺(或体检)等材料;
3. **安全技术培训**:按培训大纲完成规定学时,包括理论与实操;
4. **参加理论考试**:机考,当场出分;
5. **参加实操考试**:理论合格后按安排参加;
6. **制证与领证**:两部分均合格后,由发证机关制证发放。

## 五、考场规则与注意事项

- 带齐**准考证和身份证**,按通知提前到达考场;
- 不得携带书籍、资料、手机等电子设备进入考位;
- 按座位号入座,先核对屏幕上显示的姓名、证件号是否正确;
- 机考操作:选中答案后确认,注意**不要漏答**;交卷前系统一般会提示未作答题数;
- 即使时间充裕也不要急着交卷,至少完整复查一遍;
- 考场内保持安静,遇到设备故障立即举手报告监考人员,不要自行处理。

## 六、成绩、证书与复审

| 项目 | 说明 |
|---|---|
| 发证条件 | 理论、实操均合格 |
| 证书有效期 | **6 年** |
| 复审 | 每 **3 年**复审一次 |
| 复审要求 | 复审前应参加必要的安全培训并考试合格 |
| 证书效力 | 全国通用,跨地区作业按规定办理相关手续 |
| 证件遗失 | 向发证机关申请补发,不得使用复印件或借用他人证件 |

## 七、高频提问

| 问题 | 回答 |
|---|---|
| 理论考试多少分及格? | 一般满分 100 分,80 分及格(以当地通知为准) |
| 判断题和单选题先做哪个? | 先做有把握的判断题,把能拿的分先拿到 |
| 考试能带手机吗? | 不能,电子设备一律不得带入考位 |
| 理论没过能直接考实操吗? | 一般不能,需理论合格后按安排参加实操 |
| 证书多久复审一次? | 每 3 年一次,有效期 6 年 |
| 复审要考试吗? | 复审前应参加必要的安全培训并考试合格 |

## 八、考点提示

- ✅ 理论考试为机考,满分 100 分,**80 分及格**;
- ✅ 题型以**判断题 + 单选题**为主,部分地区有多选题;
- ✅ 证书有效期 **6 年**,每 **3 年**复审一次,复审前需参加安全培训并考试合格;
- ✅ 考试范围以法规、基础、安全技术为主,三块合计接近一半;
- ⚠️ 题量、时长、及格线、补考规则各地不同,**以考务通知为准**。

## 九、本节小结

- 理论考试是机考,当场出分,判断题 + 单选题为主,80 分及格。
- 考试内容分七大模块,法规、基础、安全技术是重点。
- 报名走"报名 → 审核 → 培训 → 理论 → 实操 → 发证"流程。
- 证书 6 年有效,3 年复审,复审前要培训并考试合格。
- 具体考务细节以当地通知为准,不要照搬别人的经验。
