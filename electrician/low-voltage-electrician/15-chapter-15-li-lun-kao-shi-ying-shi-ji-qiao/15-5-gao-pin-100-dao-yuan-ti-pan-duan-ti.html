15.5 高频100道原题-判断题 ​

说明:以下 100 道判断题按低压电工理论机考的高频考点整理,题型、问法和表述方式贴近真实机考,但不是官方真题扫描件。建议先独立判断对错,再展开每道题下方的"答案与解析"核对。判断题的破绽多在绝对词、数值、顺序上,答题技巧见 15.2 理论考试技巧总结。

使用方法:每道题控制在 20 秒以内;错题按模块归类,回到 15.3 高频易错考点总结对应条目复习。

一、安全生产法律法规(第 1~15 题) ​

1. 低压电工作业是指对 1kV 以下电气设备进行的安装、检修、运行、维护作业。( )

答案与解析

答案:√(正确)

解析:高低压以 1kV 为分界,1kV 以下(不含 1kV)属于低压电工作业范围。

2. 高压电工作业是指对 1kV 及以上电气设备进行的作业。( )

答案与解析

答案:√(正确)

解析:与上一题对应,1kV 及以上属于高压。注意"及以上"和"以下"的边界表述,考试常在这里挖坑。

3. 特种作业操作证的有效期为 3 年。( )

答案与解析

答案:× (错误)

解析:有效期为 6 年,3 年是复审周期。这是法规题最常见的混淆点。

4. 特种作业操作证每 3 年复审一次。( )

答案与解析

答案:√(正确)

解析:证书 6 年有效,每 3 年复审一次,6 年内复审两次。

5. 年满 16 周岁即可申请特种作业操作证。( )

答案与解析

答案:× (错误)

解析:必须年满 18 周岁,且不超过国家法定退休年龄。16 周岁属于未成年工,不得从事特种作业。

6. 特种作业操作证可以转借他人使用。( )

答案与解析

答案:× (错误)

解析:操作证与持证人一一对应,不得转借、涂改、伪造。转借属于违法行为,出借人和借用人都要承担责任。

7. 特种作业操作证由应急管理部门考核发证。( )

答案与解析

答案:√(正确)

解析:特种作业操作证由应急管理部门(原安全生产监督管理部门)考核发证,不是人社部门。

8. 从业人员有权拒绝违章指挥和强令冒险作业。( )

答案与解析

答案:√(正确)

解析:《安全生产法》明确赋予从业人员拒绝权,且生产经营单位不得因此降低其工资、福利待遇或解除劳动合同。

9. 从业人员发现直接危及人身安全的紧急情况时,可以先作业再报告。( )

答案与解析

答案:× (错误)

解析:此时有权停止作业或撤离,不需要"先作业再报告"。生命安全优先于作业进度。

10. 未经安全生产教育和培训合格的从业人员不得上岗作业。( )

答案与解析

答案:√(正确)

解析:这是强制性规定,不能以"边干边学""老师傅带"代替培训合格。

11. 电工可以凭经验操作,不必执行安全操作规程。( )

答案与解析

答案:× (错误)

解析:经验不能替代规程。安全操作规程是用事故教训换来的,必须严格执行。

12. 特种作业操作证复审前应参加必要的安全培训并考试合格。( )

答案与解析

答案:√(正确)

解析:复审不是简单盖章,需要通过安全培训并考试合格,确认安全能力仍然有效。

13. 特种作业操作证遗失后可以继续使用复印件上岗。( )

答案与解析

答案:× (错误)

解析:应向发证机关申请补发。使用复印件属于无证上岗。

14. 生产经营单位应当为从业人员提供符合国家标准的劳动防护用品。( )

答案与解析

答案:√(正确)

解析:提供合格的劳动防护用品是用人单位的法定义务,且不得以货币或其他物品替代。

15. 电工的岗位职责包括安全、规范、及时地完成电气设备的安装、运行、检修和维护。( )

答案与解析

答案:√(正确)

解析:这是电工岗位职责的概括表述,核心就是"安全、规范、及时"。

二、电工基础知识(第 16~30 题) ​

16. 电压是形成电流的原因,有电压就一定有电流。( )

答案与解析

答案:× (错误)

解析:有电压还要电路闭合才能形成持续电流。断路时电压存在但电流为零。

17. 电阻并联后的总电阻比其中任何一个分电阻都小。( )

答案与解析

答案:√(正确)

解析:并联相当于增大了导体的截面积,总电阻必然小于最小的分电阻。

18. 串联电路中各电阻两端的电压相等。( )

答案与解析

答案:× (错误)

解析:串联电路中电流处处相等,电压按电阻比例分配,阻值大的分得电压高。

19. 并联电路中各支路的电流一定相等。( )

答案与解析

答案:× (错误)

解析:并联各支路电压相等,电流与各支路电阻成反比。只有电阻相同,电流才相等。

20. 欧姆定律适用于线性电阻电路。( )

答案与解析

答案:√(正确)

解析:欧姆定律 I=U/R 适用于线性电阻;非线性元件(如二极管、白炽灯灯丝的高温段)电流与电压不成正比,不能简单套用。

21. 我国工频交流电的频率是 60Hz。( )

答案与解析

答案:× (错误)

解析:我国工频为 50Hz,周期 0.02s。60Hz 是部分国家和地区的标准。

22. 50Hz 交流电的周期是 0.02s。( )

答案与解析

答案:√(正确)

解析:T=1/f=1/50=0.02s。

23. 三相四线制中,线电压为 380V,相电压为 220V。( )

答案与解析

答案:√(正确)

解析:星形连接时 u线=√3·u相,380/√3≈220V。

24. 三相电源星形连接时,线电流等于相电流。( )

答案与解析

答案:√(正确)

解析:星形连接中,每相绕组与电源线串联在同一条支路上,所以线电流等于相电流。

25. 三相电源三角形连接时,线电压等于相电压。( )

答案与解析

答案:√(正确)

解析:三角形连接中,每相绕组直接接在两根电源线之间,线电压就是相电压。

26. 1 度电等于 1kW·h。( )

答案与解析

答案:√(正确)

解析:1 度 = 1kW·h = 3.6×10⁶ J。

27. 交流电有效值为 220V 时,其最大值约为 311V。( )

答案与解析

答案:√(正确)

解析:最大值 Um=√2·U≈1.414×220≈311V。绝缘耐压要按最大值考虑。

28. 纯电容电路中,电流超前电压 90°。( )

答案与解析

答案:√(正确)

解析:纯电容电流超前电压 90°,纯电感电流滞后电压 90°,这是两者的标志性区别。

29. 直流电也能使变压器正常工作。( )

答案与解析

答案:× (错误)

解析:变压器靠交变磁通感应电动势,直流电产生恒定磁场,二次侧没有感应电压,而且一次绕组可能因电阻过小而烧毁。

30. 电流的方向规定为正电荷移动的方向。( )

答案与解析

答案:√(正确)

解析:习惯上把正电荷定向移动的方向规定为电流方向,与金属中电子实际移动方向相反。

三、电气安全技术(第 31~45 题) ​

31. 我国安全电压额定值有 42V、36V、24V、12V、6V。( )

答案与解析

答案:√(正确)

解析:这就是我国安全电压的五个等级。考试有时会塞进 220V、110V 等干扰项。

32. 36V 是绝对安全电压,人体接触不会发生危险。( )

答案与解析

答案:× (错误)

解析:"安全电压"是相对概念,36V 只是一般场所的限值。潮湿、金属容器内人体电阻大幅下降,36V 也可能致命,所以那些场所要降到 12V。

33. 一般场所行灯电压不应超过 36V。( )

答案与解析

答案:√(正确)

解析:行灯是手持移动灯具,绝缘容易破损,一般场所限值 36V。

34. 在特别潮湿场所或金属容器内,行灯电压不应超过 12V。( )

答案与解析

答案:√(正确)

解析:这些场所人体电阻显著降低,行灯电压必须降到 12V 及以下。

35. 安全电压应由安全隔离变压器供电。( )

答案与解析

答案:√(正确)

解析:安全隔离变压器一、二次侧绕组分开,能防止一次侧故障电压窜入二次侧;自耦调压器做不到这一点。

36. 感知电流是人能感觉到的最小电流,工频约为 1mA。( )

答案与解析

答案:√(正确)

解析:感知电流约 1mA,摆脱电流约 10mA,危险电流约 50mA。

37. 通过人体的电流越大,触电危险性越大。( )

答案与解析

答案:√(正确)

解析:电流是触电伤害的直接因素,电流越大,热效应、化学效应和对心脏的干扰越严重。

38. 触电时间越长,危险性越大。( )

答案与解析

答案:√(正确)

解析:通电时间越长,人体电阻因出汗、灼伤而下降,电流进一步增大,心室颤动的概率显著上升。

39. 两相触电比单相触电危险性更大。( )

答案与解析

答案:√(正确)

解析:两相触电时人体承受的是线电压(380V),比单相触电的相电压(220V)更高,电流更大,也更危险。

40. 保护接地的接地电阻一般不应大于 4Ω。( )

答案与解析

答案:√(正确)

解析:保护接地要求 ≤4Ω,重复接地 ≤10Ω。

41. 重复接地的接地电阻一般不应大于 10Ω。( )

答案与解析

答案:√(正确)

解析:重复接地是保护接零的补充措施,限值比保护接地宽,为 10Ω。

42. 保护接零适用于 IT 系统。( )

答案与解析

答案:× (错误)

解析:保护接零适用于 TN 系统。IT、TT 系统采用保护接地。

43. 同一低压系统中,保护接地和保护接零可以混用。( )

答案与解析

答案:× (错误)

解析:严禁混用。混用会使接地设备外壳在故障时带上危险电压,危及所有接地设备。

44. 漏电保护器动作后,可以直接合闸继续使用,不必查明原因。( )

答案与解析

答案:× (错误)

解析:动作说明存在漏电或触电,必须先查明原因、排除故障再送电,否则可能反复跳闸甚至引发事故。

45. 漏电保护器应每月按一次试验按钮检查是否正常。( )

答案与解析

答案:√(正确)

解析:试验按钮能检查脱扣机构是否有效,应每月试跳一次。注意试验按钮不能代替接地保护。

四、电工仪表与低压电器(第 46~58 题) ​

46. 电压表应与被测电路串联。( )

答案与解析

答案:× (错误)

解析:电压表应并联。串联会因内阻大而几乎切断电路。

47. 电流表应与被测电路并联。( )

答案与解析

答案:× (错误)

解析:电流表应串联。并联相当于短接电源,会烧坏仪表。

48. 万用表可以在带电情况下转换量程。( )

答案与解析

答案:× (错误)

解析:禁止带电转换量程,转换瞬间可能产生电弧,损坏仪表甚至伤人。

49. 钳形电流表可以同时钳入两根导线测量。( )

答案与解析

答案:× (错误)

解析:只能钳一根导线。同时钳火线和零线,两者电流方向相反、磁场抵消,读数接近零。

50. 钳形电流表测量时可以在钳口闭合状态下切换量程。( )

答案与解析

答案:× (错误)

解析:必须先退出导线或断电后再换挡,带电换挡容易产生电弧、损坏仪表。

51. 兆欧表使用前应切断电源并对被测设备充分放电。( )

答案与解析

答案:√(正确)

解析:残余电荷会损坏兆欧表,也可能电击操作者,所以必须先断电、放电。

52. 兆欧表测量时转速应保持在 120r/min 左右。( )

答案与解析

答案:√(正确)

解析:额定转速约 120r/min,转速稳定测量值才准确;转速过低读数偏小。

53. 万用表可以测量绝缘电阻。( )

答案与解析

答案:× (错误)

解析:万用表电池电压低,测不出绝缘真实阻值,应使用兆欧表。

54. 熔断器既能作短路保护,也能作过载保护。( )

答案与解析

答案:√(正确)

解析:熔断器主要作短路保护,过载时熔体也会因热积累熔断,因此也具备一定的过载保护能力。

55. 热继电器可以作短路保护。( )

答案与解析

答案:× (错误)

解析:热继电器有热惯性,短路时来不及动作,只能作过载保护。

56. 接触器可以切断短路电流。( )

答案与解析

答案:× (错误)

解析:接触器灭弧能力有限,只能通断正常负载电流,短路电流必须由熔断器或断路器切断。

57. 热继电器作过载保护时,其整定电流应与电动机额定电流相适应。( )

答案与解析

答案:√(正确)

解析:整定电流一般按电动机额定电流的 1.0~1.15 倍选取,过小会误动作,过大则起不到保护作用。

58. 低压断路器一般具有短路保护和过载保护功能。( )

答案与解析

答案:√(正确)

解析:断路器通过电磁脱扣实现短路保护、热脱扣实现过载保护,部分还带欠压脱扣。

五、线路、变压器与电动机(第 59~70 题) ​

59. 选择导线截面时应考虑发热条件、电压损失和机械强度。( )

答案与解析

答案:√(正确)

解析:这三项是选择导线截面的基本依据,大电流线路还要考虑经济电流密度。

60. 铜导线的导电性能比铝导线好。( )

答案与解析

答案:√(正确)

解析:铜的电阻率更低,导电、导热和抗氧化性能都优于铝。

61. 导线接头处接触电阻增大不会影响安全。( )

答案与解析

答案:× (错误)

解析:接触电阻增大会导致局部过热、氧化加剧,形成恶性循环,可能烧断线路或引发火灾。

62. 变压器可以变换直流电压。( )

答案与解析

答案:× (错误)

解析:变压器只能变换交流电压,直流电无法在二次侧感应出电动势。

63. 变压器既能变换电压,也能变换电流和阻抗。( )

答案与解析

答案:√(正确)

解析:理想变压器可同时实现电压、电流变换,并具有阻抗变换作用,这是变压器广泛应用的基础。

64. 变压器油只起绝缘作用。( )

答案与解析

答案:× (错误)

解析:变压器油有绝缘和冷却两个作用,缺一不可。

65. 三相异步电动机的同步转速与电源频率成正比。( )

答案与解析

答案:√(正确)

解析:n1=60f/p,频率越高同步转速越高;磁极对数越多,同步转速越低。

66. 三相异步电动机的转子转速等于同步转速。( )

答案与解析

答案:× (错误)

解析:异步电动机必须略低于同步转速,存在转差才能切割磁力线产生电磁转矩。转速相等就成了同步电动机。

67. 转差率越大,说明电动机转速越低。( )

答案与解析

答案:√(正确)

解析:s=(n1-n)/n1,s 越大说明 n 越小,转速越低。

68. Y-△ 启动适用于正常运行为 Y 接法的电动机。( )

答案与解析

答案:× (错误)

解析:Y-△ 启动适用于正常运行为 △ 接法的电动机,启动时接成 Y 降压,运行时恢复 △。

69. Y-△ 启动可以降低启动电流。( )

答案与解析

答案:√(正确)

解析:星形启动时相电压降为 1/√3,启动电流降为直接启动的 1/3。

70. 任意对调两相电源线可以改变三相异步电动机的转向。( )

答案与解析

答案:√(正确)

解析:对调两相会改变旋转磁场的方向,从而实现反转。

六、配电、照明与防雷接地(第 71~82 题) ​

71. 照明开关应接在零线上。( )

答案与解析

答案:× (错误)

解析:开关必须接在相线上。接零线时关灯后灯头仍带电,换灯泡容易触电。

72. 螺口灯头的螺纹部分应接相线。( )

答案与解析

答案:× (错误)

解析:中心触点接相线,螺纹部分接零线。螺纹容易外露,接零线更安全。

73. 单相三孔插座的接线是左零右火上接地。( )

答案与解析

答案:√(正确)

解析:面对插座看,左零、右火、上接地。

74. PE 线应采用黄绿双色线。( )

答案与解析

答案:√(正确)

解析:黄绿双色是保护线专用色,任何情况下不得挪作相线或零线使用。

75. 三相五线制中,PE 线和 N 线是分开的。( )

答案与解析

答案:√(正确)

解析:三相五线制就是 TN-S 系统,N 线与 PE 线全程分开。

76. 避雷针的作用是阻止雷云放电。( )

答案与解析

答案:× (错误)

解析:避雷针是"引雷"装置,把雷电流引入大地,不是阻止雷云放电。

77. 防雷装置由接闪器、引下线和接地装置组成。( )

答案与解析

答案:√(正确)

解析:接闪器接雷、引下线导雷、接地装置泄雷,三者缺一不可。

78. 独立避雷针的接地电阻一般不应大于 10Ω。( )

答案与解析

答案:√(正确)

解析:独立避雷针接地电阻 ≤10Ω,以保证雷电流快速泄放。

79. 电能表是用来测量电功率的仪表。( )

答案与解析

答案:× (错误)

解析:电能表测量的是电能(kW·h),不是电功率(kW)。

80. TN-C 系统中 PEN 线兼作中性线和保护线。( )

答案与解析

答案:√(正确)

解析:C 表示 Combined,PEN 线合并了 N 和 PE 的功能,即三相四线制。

81. 在 TN 系统中,设备外壳应与 PE 线或 PEN 线连接。( )

答案与解析

答案:√(正确)

解析:TN 系统采用保护接零,设备外壳必须与 PE 线(TN-S)或 PEN 线(TN-C)可靠连接。

82. 接地线应尽量短、直,以减小接地电阻。( )

答案与解析

答案:√(正确)

解析:接地线越短、越直,电阻和电感越小,故障电流泄放越快。

七、防火防爆、触电急救与作业规范(第 83~100 题) ​

83. 电气火灾可以用水直接扑救。( )

答案与解析

答案:× (错误)

解析:带电情况下水导电,不能用水扑救。必须先切断电源;断电后也要防止水浸入设备造成损坏。

84. 带电灭火可以使用泡沫灭火器。( )

答案与解析

答案:× (错误)

解析:泡沫灭火剂导电,禁止用于带电灭火。带电灭火只能用干粉或二氧化碳。

85. 干粉灭火器和二氧化碳灭火器可用于带电灭火。( )

答案与解析

答案:√(正确)

解析:这两类灭火剂不导电,是带电灭火的常用选择,但仍应保持安全距离。

86. 发现有人触电,应立即用手将其拉开。( )

答案与解析

答案:× (错误)

解析:徒手拉人会让救人者一起触电。应先断电,或用干燥木棒、绝缘工具使其脱离电源。

87. 触电急救应先使触电者脱离电源,再就地抢救。( )

答案与解析

答案:√(正确)

解析:脱离电源是急救的前提,之后立即就地实施心肺复苏,不要盲目搬动或长途送医而耽误抢救。

88. 心肺复苏的胸外按压与人工呼吸比例为 30:2。( )

答案与解析

答案:√(正确)

解析:成人心肺复苏为按压 30 次、吹气 2 次。

89. 成人心肺复苏的按压频率为每分钟 60 次。( )

答案与解析

答案:× (错误)

解析:应为 100~120 次/分。60 次/分太慢,无法形成有效循环。

90. 触电者心跳呼吸停止时,应立即进行心肺复苏并拨打急救电话。( )

答案与解析

答案:√(正确)

解析:一边施救一边呼救,两者同时进行,不能只等救护车。

91. 停电作业的顺序是停电、验电、装设接地线、悬挂标示牌和装设遮栏。( )

答案与解析

答案:√(正确)

解析:这就是"停、验、接、挂、遮"的标准顺序,不能颠倒。

92. 装设接地线应先接导体端,后接接地端。( )

答案与解析

答案:× (错误)

解析:必须先接接地端,后接导体端;拆除时顺序相反。这样可避免人体串入回路。

93. 验电前应在有电的设备上验证验电器是否良好。( )

答案与解析

答案:√(正确)

解析:先在有电设备上确认验电器能正常指示,再去验停电设备,防止验电器本身失效造成误判。

94. 在低压设备上工作不需要办理任何手续。( )

答案与解析

答案:× (错误)

解析:应办理工作票或工作许可手续,落实停电、验电、接地、挂牌等安全措施。

95. 安全标识中的红色表示禁止和停止。( )

答案与解析

答案:√(正确)

解析:红色表示禁止、停止;黄色警告、蓝色指令、绿色提示。

96. 爆炸危险场所可以使用普通电气设备。( )

答案与解析

答案:× (错误)

解析:必须使用防爆型电气设备,普通设备的电火花或高温可能引燃爆炸性混合物。

97. 电气设备着火时,应先切断电源再灭火。( )

答案与解析

答案:√(正确)

解析:先断电是电气灭火的第一原则,既能防止触电,也能避免灭火剂导电造成短路。

98. 从业人员应当正确佩戴和使用劳动防护用品。( )

答案与解析

答案:√(正确)

解析:这是从业人员的法定义务,也是保护自身安全的最后一道防线。

99. 检修电气设备时可以约时停送电。( )

答案与解析

答案:× (错误)

解析:严禁约时停送电。时间误差可能导致检修人员触电,必须由专人按规定程序停送电并确认。

100. 电气作业完成后,应清理现场、恢复安全设施,并做好记录。( )

答案与解析

答案:√(正确)

解析:工作终结包括清理现场、拆除接地线和标示牌、恢复安全设施、办理工作票终结手续并做好记录。
