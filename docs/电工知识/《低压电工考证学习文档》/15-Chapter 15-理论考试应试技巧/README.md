# 第 15 章 理论考试应试技巧

本章专门应对**理论机考**。先把考试本身摸清楚(形式、题型、分值、报名与考场规则),再给出判断题和单选题的具体答题方法,然后把最容易混淆、最容易丢分的高频考点集中对比,最后用 100 道选择题 + 100 道判断题做集中训练。每道题都配有折叠的答案与详细解析,建议先自己做,再展开核对。

**本章考点**:考试形式与及格线、判断题/单选题答题技巧、安全电压与安全电流、接地与接零的区别、操作顺序类规范、触电急救与电气灭火要点。

## 学习提示

- 15.1~15.3 先通读一遍,建立"考什么、怎么答、哪里容易错"的整体框架。
- 15.4、15.5 建议掐时间做:单选题控制在 40 秒/题以内,判断题 20 秒/题以内。
- 做错的题不要只记答案,回到 15.3 或对应章节找知识点,弄懂"为什么"。
- 题库按高频考点整理,用于训练答题感觉,不是官方真题扫描件;具体考务以当地通知为准。
